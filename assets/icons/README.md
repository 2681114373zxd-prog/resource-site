# assets/icons/ · 软件图标目录

把软件的图标图片放在这里（SVG 或 PNG 都可以），然后在 `data/apps.json` 里写：

```json
"icon": "assets/icons/mytool.svg"
```

几点说明：

- 建议尺寸：正方形，SVG 最好；PNG 建议 128×128 或 256×256，**不要用特别大的图片**（会拖慢手机加载）。
- 路径可以写 `assets/icons/xx.svg`（推荐），也可以写完整的 `https://...` 外链。
- **不写 `icon` 也没关系**：网站会自动根据软件名生成一个带渐变的「首字母方块」，风格统一、也很好看。
- 图标加载失败时同样会自动回退成首字母方块，不会出现破图。

## 自己在网上找的图标算侵权吗？

软件的官方 Logo 通常受版权/商标保护，个人下载站引用一般属于「指示性使用」，
但如果对方明确禁止，请换成自己画的图标或直接用自动生成的首字母方块。
