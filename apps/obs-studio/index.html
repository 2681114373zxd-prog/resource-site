软件介绍

OBS Studio 是使用最广泛的开源录屏 / 直播软件，支持多场景切换、窗口采集、麦克风降噪、虚拟摄像头等。

  • 录屏、直播、虚拟摄像头三合一
  • 支持 Windows / macOS / Linux
  • 插件生态丰富，可扩展性很强

提示：直播推流需要填写平台给你的推流地址与密钥，请自行从平台后台获取。
