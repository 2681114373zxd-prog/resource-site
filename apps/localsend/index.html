软件介绍

LocalSend 是一款开源、跨平台的文件传输工具，手机、电脑只要连在同一个 Wi-Fi 下就可以互传文件。

不需要账号、不需要联网、不经过服务器，所有传输都在局域网内直接进行，速度取决于你的路由器。

  • 支持 Windows / macOS / Linux / Android / iOS
  • 自动发现同一网络中的设备，也可扫码配对
  • 传输过程加密，文件不落第三方服务器

适合在手机和电脑之间传安装包、照片、文档。
