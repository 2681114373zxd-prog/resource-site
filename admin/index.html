打开网站

连接 GitHub

这个页面是在线后台：发布时由你的浏览器直接调 GitHub API，安装包进 Releases， data/apps.json 直接提交，随后 GitHub Actions 会自动重新构建网站。 令牌只存在你这台电脑的浏览器里，只发给 api.github.com。

令牌怎么建？

GitHub → 右上角头像 → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token，然后：

① Repository access 选 Only select repositories，只勾 resource-site； ② Permissions → Repository permissions → Contents 选 Read and write； ③ 生成后那串 github_pat_… 只会显示一次，复制过来粘在上面。

只给这一个仓库、只给 Contents 读写就够了，别开全仓库权限。不用了随时在 GitHub 上撤销。
